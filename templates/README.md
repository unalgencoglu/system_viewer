# Uygulamayı çalıştırmak için:

# Python ve Flask indirin:
sürüm: 3.13.12
pip install flask

# Sanal ortamı aktifleştirin:
python -m venv venv (windows)
python3 -m venv venv (linux)

aktif etme: 
venv\Scripts\activate.bat (windows)
source venv/bin/activate (linux)

terminalde (venv) yazısını göreceksiniz

# Sunucuyu çalıştırın:
Terminalde python web_app.py yazarak çalıştırabilirsiniz sonrasında
http://127.0.0.1:5000 linkine gidin, burada uygulamayı görüntüleyebilirsiniz
